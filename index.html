Load & Parse

🔬

Quality Control

Filter spots and genes by count thresholds, mitochondrial percentage, and spatial tissue mask.

Library-size normalization to 10,000 counts per spot followed by log1p transformation.

Identify highly variable genes using the Seurat v3 method for downstream dimensionality reduction.

PCA on HVGs, followed by neighborhood graph construction and UMAP embedding.

Quickstart

Up and running in minutes

Install dependencies, point to your data folder, and run.

1. Install dependencies

$ pip install -r requirements.txt

2. Run the pipeline

pipeline.py — minimal usage
from pipeline import VisiumHDPipeline

# Point to your Space Ranger output folder
pipe = VisiumHDPipeline(
    data_dir="/path/to/spaceranger/output",
    bin_size=8,           # μm binning: 2, 8, or 16
    output_dir="./results",
)

# Run full pipeline end-to-end
adata = pipe.run()

# Or run steps individually
adata = pipe.load()
adata = pipe.qc(adata, min_counts=100, max_mt_pct=20)
adata = pipe.normalize(adata)
adata = pipe.cluster(adata, resolution=0.5)
pipe.plot_spatial(adata, color="leiden")
